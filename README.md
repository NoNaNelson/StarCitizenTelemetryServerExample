# StarCitizenTelemetryServerExample
an example on how to use the telemetry server in star citizens 5.0 PTU patch 13238477


## setup

```
python -m venv .venv
pip install
pip install grpcio

source .venv/bin/activate
```


## run

```
python main.py
```


you can figure out the rest yourself
